📖 Panduan Penggunaan & Walkthrough

📐 Susun Atur Grid Label (90mm x 60mm)

Label ubat direka khas mengikut lakaran grid 3 lajur:

Lajur Kiri (22mm)
Nama Ubat (Menegak)
Lajur Tengah (46mm)
Jadual (Dos / Masa / Makan)
Lajur Kanan (22mm)
Amaran Khas (Kotak Kuning)
  • Lajur Kiri: Nama dan kekuatan ubat secara menegak (putar 90°).
  • Lajur Tengah: Jadual ubat — bilangan biji (dos), waktu, dan kaitan makan.
  • Lajur Kanan: Lambang amaran disusun menegak dalam kotak amaran kuning.

⊕ Simbol & Pecahan Dos

Simbol dos ubat menggunakan reka bentuk tablet terbelah (scored tablet):

1 Biji
1/2 Biji
2 Biji

🖨️ Tip Pencetakan Label (90mm x 60mm)

  1. Pilih pencetak label anda (cth: TSC, Zebra, Brother).
  2. Tetapkan Saiz Kertas kepada 90mm x 60mm.
  3. Set Margin kepada Tiada (None).
  4. Aktifkan Grafik Latar Belakang (Background graphics).
